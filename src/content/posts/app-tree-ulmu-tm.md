# App.tree

**App tree** es una herramienta web que procesa archivos JSON generados por la aplicación desktop AnalizadorSSH, permitiendo visualizar de manera interactiva la estructura de carpetas analizadas. Facilita la colaboración entre usuarios al permitir compartir información sobre el contenido de carpetas sin necesidad de acceso físico a los archivos

### ✨ Características principales

  *  Visualización interactiva: Explora la estructura de carpetas en formato de árbol
  *  Metadatos completos: Información detallada de cada nodo (peso, fecha creación, ruta, cantidad de hijos, creador)
  *  Información del disco: Muestra datos completos del análisis (número de serie, responsable, capacidad, etc.)
  *  Compartición fácil: Permite compartir estructuras de carpetas con otros usuarios
  *  Interfaz intuitiva: Diseño limpio y fácil de usar

### 🚀 Cómo usar

  -  Genera el archivo JSON usando la aplicación desktop AnalizadorSSH
  -  Accede a la aplicación web: https://app.tree.ulmu-tm.com/
  -  Carga el archivo JSON en la interfaz web
  -  Explora la estructura de carpetas de manera interactiva
  -  Comparte el archivo JSON con quienes necesiten ver la estructura
